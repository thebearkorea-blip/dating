# 2단계 앱 UI 레퍼런스 조사 (2026-11-13)

대상: 웹 PWA, 가상 아이돌 연습생과 1:1 메신저 관계, 18+, 비성적.
방법: 웹 검색 결과 요약만 근거(공식 도움말·스토어 페이지·리뷰 기사). 이미지 저장 없음. 앱을 직접 설치해 본 것이 아니므로 화면 세부는 "검증 한계"에 표시했다.

## 제약 (설계 전제)

1. 카카오톡·라인 디자인 복제 금지(부정경쟁방지법). 말풍선 색·꼬리·아이콘 배치를 그대로 따라 하지 않는다.
2. 앱이 사용자에게 직접 말하는 화면(팝업·튜토리얼·결제창)은 최소화한다.
3. 숫자(애정도) 비노출.
4. AI 고지는 가입 시 1회 + 프로필의 작은 표시.

## 검증 한계 (먼저 읽을 것)

- 검색 결과는 요약 수준이다. 말풍선 모양·입력창 배치·"입력 중" 애니메이션 같은 픽셀 단위 화면은 이번 자료에서 확인하지 못했다. 화면 설계 전에 각 앱 스토어 스크린샷을 직접 열어 볼 것.
- iMessage·Telegram·Instagram의 "입력 중" 표시, WhatsApp 음성 파형은 근거 자료를 찾지 못했다(아래 1번은 읽음 처리 중심).
- Linky·Zeta의 구독 안내 화면 위치, Mystic Messenger의 SNS 피드, Love and Deepspace의 메신저 내 일정 표현, bubble 구독 화면 캡처는 직접 근거를 찾지 못했다. 해당 칸에 "미확인"으로 적었다.
- 리뷰 기사 다수는 제휴·비교 블로그라 수치(가격·평점)는 참고용이다.

## 5. 버블(bubble, Dear U)

근거: [나무위키 Dear U bubble](https://namu.wiki/w/Dear%20U%20bubble), [App Store bubble with STARS](https://apps.apple.com/kr/app/bubble-with-stars/id1556582179), [App Store bubble for CUBE](https://apps.apple.com/kr/app/bubble-for-cube/id6446391870), [Dear U 스토어 구매 페이지](https://store.dearu.com/STARS/home/startalk/PRO1713313189I2E1q/buying?lang=ko&currency=KRW).

- 화면 구성: 아티스트와의 1:1 채팅방 형태. 메시지에서 팬 닉네임이 자동 치환되어 "나에게만 보낸 듯" 느낌을 만든다. 구독 첫날부터 Day 1 기념일 표시. 월 구독(RESCENE 멤버당 ₩4,500 표기), 구독 후 메시지만 열람.
- 강점: 닉네임 치환·기념일 같은 **숫자가 아닌 개인화 표시**. 구독 설정이 이용권 구매 화면에서 이뤄지고 대화방은 메시지 중심.
- 우리가 피할 것: 구독일 수와 답장 가능 글자 수 연동(결제 오류·인원 변경 시 초기화 불만), 아티스트별 닉네임 불가 불만, 답장이 어떤 메시지에 대한 것인지 불분명하다는 지적(스레드 맥락 UI 부족). 평점 3.0(970개)·3.2(38개)로 낮음. 구독 화면 구성 캡처는 **미확인**(스토어 스크린샷 직접 확인 필요).
- 주의: 실존 아이돌 팬 서비스와 달리 우리는 가상 인물이라 "나에게만"이 AI 고지와 충돌하지 않도록 프로필 표기가 필요.
