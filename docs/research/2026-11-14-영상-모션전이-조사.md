## 3. 참조 모션 영상의 적법성 (법률 자문 아님)
- 남의 영상(먹방 등)을 가져와 얼굴만 바꾸면 원 영상의 저작권(2차 저작·복제)과 출연자의 초상권·퍼블리시티권 문제가 남는다. 얼굴을 바꿔도 몸·동작·장면은 남의 것이다. 조코딩 방법 1은 이 위험이 크다고 본다(판단).
- TikTok: 사적 개인의 동의 없는 AI 초상은 금지, 현실적 AI 콘텐츠는 라벨 필수, 미라벨은 삭제·제한 가능. 얼굴 교체는 공개 대상 예시. 출처 https://www.tiktok.com/community-guidelines/en/integrity-authenticity , https://www.tiktok.com/creator-academy/en/article/ai-generated-content-label (본문 직접 확인 못 하고 제3자 요약 https://storrito.com/resources/tiktoks-2026-ai-labeling-rules-and-what-they-signal-for-platform-governance/ 로 확인, 원문 재확인 필요).
- 대안별 적합도:
  1. 직접 촬영 영상 + 얼굴 교체: 권리 문제 없음(본인 영상). 단 본인 몸이 나오므로 남성 아이돌 체형·동작은 본인이 연출해야 함. **적합 1순위**.
  2. Pexels/Pixabay: Pexels는 상업 이용·수정 허용, 식별 가능한 인물을 나쁘게 묘사 금지, 제품 보증 암시 금지, AI 관련 조항 없음(미명시). https://www.pexels.com/license/ . 인물 영상의 모델 릴리스 여부는 라이선스 페이지에 없음 = 초상권 안전 보장 아님. 인물 없는 배경·손·사물 컷은 안전, 인물 모션 전이는 비추천. Pixabay는 **미확인**.
  3. 완전 생성(i2v): 권리 문제 가장 적음. 동작 통제력은 낮고 부자연 동작 위험.

## 4. 선택과 1차 실험
**채택 1: (b) + 대안1** = 직접 찍은 5~8초 동작 영상(안무·돌아보기·웃기) + 이한 LoRA 이미지 -> Kling v3.0 motion-control. 1순위 경로는 Gateway(`klingai/kling-v3.0-motion-control`), 호출 형식 미확인이면 fal `fal-ai/kling-video/v3/pro/motion-control`로 대체.
**채택 2: (a)** = LoRA 정지 이미지 -> Kling v3.0 i2v(Gateway). 참조 영상 없이 쓰는 완전 생성 대안·배경 컷용.

1차 실험(실행은 사용자 확인 필요: 유료 호출 한도)
- 클립: 9:16, 720p, 길이 6초. (b) 6장(직접 촬영 3종 x std/pro 비교) + (a) 6장(프롬프트 3종 x 2 시드). 12장.
- 예상 비용: (b) 6초 x std 0.126 x 3 + pro 0.168 x 3 = 약 $3.8. (a) 6초 x std 0.168 x 6 = 약 $6.0. 합계 약 $10(약 14,000원 안팎, 환율 가정). 실패·재생성 여유 포함 $15 상한 제안.
- 판정(장당 1~5점, 이한 이미지·정지 기준 사진과 비교):
  - 얼굴 일치: 3프레임 이상에서 같은 인물로 보이는가(4점 이상 통과)
  - 나이 인상: 21세 성인으로 보이고 미성년 인상이 없는가(1장이라도 어려 보이면 해당 설정 탈락)
  - 부자연 동작: 손·관절·입 모양 깨짐 없는가(4점 이상)
  - 통과선: 12장 중 6장 이상이 세 항목 모두 통과, 그리고 틱톡 AI 라벨 달고 올릴 수 있는 수준이라고 사용자가 판단.
- 오디오: Kling motion-control은 무음. 음원은 틱톡 사운드/별도 TTS로 입힌다(별도 확인 필요).
