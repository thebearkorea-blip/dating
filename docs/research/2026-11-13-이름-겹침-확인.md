# 이름 겹침 확인 (W1b, 설계서 §4-7)

> 2026-11-13 웹 검색 각 1회(영문·국문). 한계: 검색은 미국 기반 일반 웹 검색이며 KIPRIS(상표)·한국 연예인 DB 직접 조회는 하지 않았다. 따라서 "없음"은 "검색에서 안 나옴"이지 "법적으로 안전"이 아니다. 출시 전 상표 검색과 얼굴 유사도 검사는 별도(lines.md B6).

세 멤버 이름이 한 그룹에서 함께 쓰이는 K-팝 그룹은 검색에서 찾지 못했다.

## 판정

- 설계서 §4-7("겹치는 이름이 없음")은 **이 결과로는 미충족**: NOWA가 Nowz 약칭과 근접. 사용자가 NOWA를 유지한다면 "근접 이름이지만 다른 그룹"으로 받아들이는 결정이 필요(결정 필요, decisions에는 반영하지 않음).
