# LoRA 라이선스·유사도 조사 (2026-11-13)

확인 날짜: 2026-11-13. 표시: [공식]=BFL·fal·AWS·MS·TikTok 등 1차 페이지, [2차]=블로그·포럼·제3자 요약, [가정]=내 추정.
한계: WebFetch는 소형 모델이 페이지를 요약해 준 결과다(인용은 요약기 반환 문구). 법률 자문 아님. 핵심 결론은 변호사·BFL 서면 확인 전까지 "미확정"으로 취급.

## 1. BFL 라이선스

### (a) 산출물(이미지) 상업 이용 — 허용 문구 있음, 단 상충 조항 있음
- FLUX.1 [dev] 라이선스 §2(d) [공식] https://huggingface.co/black-forest-labs/FLUX.1-dev/blob/main/LICENSE.md :
  "You may use Output for any purpose (including for commercial purposes), except as expressly prohibited herein." 또 "Outputs are not considered Derivatives under this License." 단 경쟁 모델 학습·파인튜닝·증류에 Output 사용 금지.
- 상충 조항 §4(a) [공식 동일 문서]: 모델·파생물 사용을 "(i) for any commercial or production purposes" 로 제한. §1(c) Non-Commercial Purpose 정의: "only so far as you do not receive any direct or indirect payment arising from the use", 수익 창출 활동·최종 사용자와의 직접 상호작용은 비상업이 아님.
- 해석 [가정]: 산출물은 §2(d)로 상업 가능, 그러나 모델/LoRA를 "상업·생산 목적으로 구동"하는 것은 §4(a)에 걸린다. 두 조항의 충돌 해소는 BFL 서면이 없음.
- HF 모델카드 [공식] https://huggingface.co/black-forest-labs/FLUX.2-dev : "Generated outputs can be used for personal, scientific, and commercial purposes." 동시에 "This model falls under the FLUX Non-Commercial License."
- BFL licensing 페이지 FAQ [공식] https://bfl.ai/licensing : "Our license allows you to use model outputs commercially, and we make no ownership claim over those outputs."
- 의무(§2(e)): 콘텐츠 필터 또는 산출물 검토 유지, 그리고 법이 요구하는 범위에서 "Output includes disclosure (or other indication) that the Output was generated or modified" (AI 생성 표시). 이 의무가 본 프로젝트(AI 표시)와 직결.
- FLUX.1 [schnell]: Apache-2.0, "can be used for personal, scientific, and commercial purposes" [공식] https://huggingface.co/black-forest-labs/FLUX.1-schnell
- FLUX.1 [pro]/FLUX.2 [pro]: 이번 조사에서 BFL의 pro 라이선스 원문은 직접 확인하지 못함. 2차 소스는 "pro 이상은 API 통한 상업권 명시"라 함 [2차] https://www.promptzone.com/zuzanna_choi/flux-ai-license-key-insights-2g8d . BFL 자체 API 사용 시 상업권 포함은 [2차] 수준(원문 미확인).
- FLUX.2 [dev]: 비상업 라이선스(위 모델카드). FLUX.2 [klein] 4B = Apache 2.0, 9B = 비상업 [공식] https://huggingface.co/black-forest-labs/FLUX.2-klein-4B

### (b) 학습한 LoRA 가중치의 상업 이용·배포
- dev 라이선스: "Any restrictions set forth herein regarding the FLUX.1 [dev] Model also apply to any Derivative you create"; Derivative는 "customized or fine-tuned version" 포함 [공식]. 즉 dev 기반 LoRA 가중치는 §4(a) 상업·생산 목적 금지가 그대로 적용된다고 읽힘 [가정: LoRA=Derivative는 문언상 자연스러운 해석이나 BFL의 명시 확인은 없음].
- 배포 시: 라이선스 사본 제공(§3(a)), 파생물이면 Attribution Notice에 수정 사실 명시(§3(c)) [공식].
- BFL 상업 길: "You can self-host a FLUX model, fine-tune it on your own data, create LoRAs and other derivatives" (Self-Hosted 상업 라이선스 대상) [공식] https://bfl.ai/licensing . 같은 페이지: 표준 라이선스는 "does not permit hosting an external-facing API endpoint". Self-Hosted Commercial License Terms 원문 [공식] https://bfl.ai/legal/self-hosted-commercial-license-terms : "FLUX [dev]" 모델 대상, 요금은 구독/선불로 "pricing page" 참조(구체 금액 미확인), 사용자에게 API로 제공하려면 sales 문의.
- fal에서 학습 후 내려받은 LoRA를 HF에 올린 예는 라이선스를 flux-1-dev-non-commercial-license로 표시 [2차] (WebSearch 요약, 개별 repo 미확인).
- 결론: fal 밖(내 PC·다른 클라우드)에서 dev LoRA로 생성해 상업 운영하는 것은 위험. fal 안에서만 학습·생성하는 경로가 상대적으로 안전하나 (c) 참조.

### (c) fal·Replicate 같은 호스팅 이용 시 상업 라이선스 포함 여부
- fal flux-lora 모델 페이지 [공식] https://fal.ai/models/fal-ai/flux-lora : "All generated images are cleared for commercial use" / "Commercial usage rights included" / 요금 $0.035 per megapixel.
- fal LoRA 학습 페이지 [공식] https://fal.ai/models/fal-ai/flux-lora-fast-training : "Commercial usage rights included for trained models", "$2 per training run (scales linearly with steps)".
- fal ToS [공식] https://fal.ai/terms : §14(b) 제3자 모델 사용은 "may be subject to additional terms"; §4(a) 이용 허락은 "for your own personal or internal business use"; 산출물 소유권·LoRA 가중치 소유는 명시 없음(요약기 반환).
- Replicate 블로그를 인용한 HF 토론 [2차] https://huggingface.co/black-forest-labs/FLUX.1-dev/discussions/59 : "If you generate images on Replicate with FLUX.1 models and their fine-tunes, then you can use the images commercially." / "If you download the weights off Replicate and generate images on your own computer, you can't use the images commercially." 한 사용자가 BFL에 이메일해 받았다는 입장(전언): Replicate에서 학습+추론 모두 하면 상업 OK, 다른 곳이면 비상업. BFL 직원 직접 답변은 없음.
- 상충: dev 라이선스 §4(a)(비상업) vs fal "Commercial usage rights included". fal이 BFL과 별도 상업 계약을 가졌을 가능성이 높지만 그 계약 문서는 공개 확인 못 함 [가정]. 호스팅 이용자의 권리가 fal 계약을 통해 이전되는지 fal 서면 확인 필요.
- 요약: "fal에서 학습·생성한 이미지(산출물)"는 (a)·(c) 두 근거로 상업 사용 근거가 가장 두껍다. "LoRA 가중치를 들고 나가는 것"은 근거가 얇다.

## 2. 상업 이용이 분명한 대안 (2개)
1. FLUX.2 [klein] 4B — Apache 2.0 [공식] https://huggingface.co/black-forest-labs/FLUX.2-klein-4B . fal 트레이너 존재: 출시 안내 [공식 SNS] https://x.com/fal/status/2013313891057455265 (klein 4B/9B Base LoRA 학습). 단 9B는 비상업이므로 4B만 선택. 가격은 소스마다 다름 [2차]: 초기 $5/1000step(4B), fal 4B base trainer 페이지는 deprecated 표시 및 $0.005/step 라는 GitHub 이슈 보고 https://github.com/ceponatia/vesper/issues/565 . 현재 4B 트레이너 지원 여부는 fal 페이지에서 직접 재확인 필요(내 fetch는 404).
2. FLUX.1 [schnell] — Apache 2.0 [공식]. 추론은 fal $0.003/MP [공식 https://fal.ai/pricing]. 다만 fal에 schnell 전용 LoRA 학습 엔드포인트 존재는 확인 못 함 [미확인]. 로컬 학습은 가능하나 schnell은 증류 모델이라 LoRA 학습이 까다롭다는 점은 일반 상식 [가정].
- 참고: SDXL base 1.0 = CreativeML Open RAIL++-M [공식 표기] https://huggingface.co/stabilityai/stable-diffusion-xl-base-1.0 . 모델카드에 명시적 상업 문구는 없음(요약기 기준, "research purposes" 문구도 있음). OpenRAIL++-M은 일반적으로 상업 허용이나 원문 미확인 [가정]. fal SDXL 트레이너 가격·존재 확인 못 함. fast-sdxl 추론은 $0.1/MP 표기 [공식 페이지, 일부 소스는 placeholder 의심].
- 로컬 klein 4B LoRA 학습: 24GB VRAM, 4090 약 1시간, 대여 약 $0.5 [2차] https://huggingface.co/blog/black-forest-labs/flux-2-klein-lora (검색 요약 기준).
- 화질·실사 일관성은 dev 대비 열세일 수 있음 [가정, 비교 검증 안 함].

## 4. 실존 인물 유사도 검사
(a) 상용 API
- AWS Rekognition: RecognizeCelebrities는 Group 2 이미지 API, 첫 100만 장 $0.0010/장; CompareFaces는 Group 1, 동일 $0.0010/장 [공식, 가격표 표는 예시 문구 기준] https://aws.amazon.com/rekognition/pricing/ . 무료 1,000장/월(12개월). 설명 [공식] https://docs.aws.amazon.com/rekognition/latest/dg/celebrities.html : "tens of thousands of well-known personalities", "international, widely known celebrities like actors, sportspeople, and online content creators". 한국 연예인 커버리지는 문서상 미확인 [미확인]. 한 2차 소스는 중국 인플루언서 커버리지가 제한적이라 함.
- Azure Face: 식별·검증은 Limited Access, 등록·Microsoft 관리 고객만, S0/E0만 [공식] https://learn.microsoft.com/en-us/azure/ai-foundry/responsible-ai/computer-vision/limited-access-identity . 유명인 인식은 2022-06부터 managed customer 한정 [2차]. 1인 개발자에게는 사실상 불가.
- Google Cloud Vision 유명인 인식: 2025-09-16 이후 제거 예정 공지 [2차, 공식 공지 미확인].
- Face++: 운영 중이나 전용 유명인 인식 기능 언급 없음, 수출 규제 이슈 언급 [2차].
(b) 오픈소스 자체 DB: InsightFace 코드는 MIT이나 사전학습 모델은 비상업 연구 전용, 상업 라이선스는 별도 문의 [공식 insightface.ai]. 상업 안전 대안으로 YuNet+SFace(Apache 2.0) 언급 [2차 LocalAI]. 연예인 사진 DB 구축은 초상·저작권·개인정보 부담과 한국 연예인 수천 명 수집 노동이 커서 1인 현실성 낮음 [가정]. 오탐 기준(코사인 유사도 임계값) 설정도 직접 해야 함.
(c) 역이미지 검색: Google Lens·TinEye 수동 검사 — 공식 정책 페이지는 미확인, 비용 0원이나 "닮음"을 찾는 용도가 아니라 동일/유사 이미지 매칭 위주 [가정].
- 현실 조합(월 30만 원 이내) [가정]: ① 최종 후보 100~300장 중 대표 샘플·최종 채택 얼굴에 AWS RecognizeCelebrities 일괄 호출(300장×$0.001≈$0.3, 사실상 무료) ② 얼굴을 확정한 뒤 Google Lens/TinEye로 수동 검사 ③ (선택) 지인·사용자 몇 명의 한국 연예인 닮음 의견. 주의: AWS 유명인 DB에 없는 한국 연예인은 "미검출"이어도 안전하다는 증거가 못 됨.

## 5. AI 생성 표시 (C2PA)
- fal: "Every piece of media generated through fal's hosted applications is signed with Content Credentials (C2PA)" + 비가시 워터마크, "Live/streamed generation is not currently signed" [공식] https://fal.ai/verify . 즉 별도 작업 없이 fal 산출물에 C2PA가 붙을 수 있으나, 구성에 따라 서명이 생략될 수 있고(문구 "configurations that don't apply signing") 재저장·스크린샷·압축으로 쉽게 사라진다. 실제 FLUX 산출물 파일에서 manifest가 붙는지는 직접 시험 안 함 [미확인]. BFL: 제3자 추론 환경 산출물에는 "does not attach or validate Content Credentials" [공식] https://help.bfl.ai/articles/3705384267-c2pa-in-flux-generated-images .
- TikTok: C2PA Content Credentials를 읽어 AIGC를 자동 라벨한다고 공지 [공식] https://newsroom.tiktok.com/en-us/partnering-with-our-industry-to-advance-ai-transparency-and-literacy . 비가시 워터마크·감지 모델 병행은 [2차].
- Instagram/Meta: 공식 글은 "industry standard AI image indicators"로 감지해 라벨을 단다고만 표현(C2PA·IPTC 명시 없음) [공식] https://about.fb.com/news/2024/04/metas-approach-to-labeling-ai-generated-content-and-manipulated-media/ . C2PA/IPTC 기반 자동 "AI info" 라벨은 [2차]. 최신(2026) 정책은 공식 페이지 미확인.
- 본 프로젝트: 가상 캐릭터임을 계정에서 직접 밝히고 플랫폼 AI 표시 토글을 켜는 것이 안전 [가정]. BFL dev 라이선스 §2(e)도 표시를 요구(법이 요구하는 범위).
- 한국 AI 기본법·EU AI Act 표시 의무의 정확한 범위는 이번에 조사하지 않음 [미확인]. 2차 소스는 EU 투명성 의무가 2026-08-02 시행이라 함.

## 요약 (추천 경로 1개)
1. 추천: fal에서 FLUX.1 [dev] 대신 **FLUX.2 [klein] 4B(Apache 2.0)로 LoRA를 학습**해 가중치 라이선스 불확실성을 제거하고, 보조로 Kontext [pro] ($0.04/장)를 일관성 보정에 쓴다. (dev LoRA를 fal 안에서만 쓰는 차선책은 fal "commercial rights included" 문구에 의존)
2. 비용: 학습 약 $5~10/회, 생성 klein/Kontext 수백 장 $수~수십, AWS 유명인 검사 약 $0.3 → 월 약 3~10만 원, 30만 원 예산 내. 단가는 fal 페이지 재확인 필요.
3. 유사도: AWS RecognizeCelebrities + Google Lens/TinEye 수동 검사 조합. AWS DB 밖 한국 연예인은 못 잡음.
4. 표시: fal C2PA는 자동 서명되나 쉽게 소실되므로 계정 소개·플랫폼 AI 토글로 직접 표시.
5. 남은 법적 불확실성: dev §2(d) vs §4(a) 충돌과 fal이 BFL로부터 받은 권리의 범위(공개 문서 없음), 실존인물 닮음에 따른 퍼블리시티권·초상 분쟁(한국 법 미조사), 한국·EU 표시 의무 범위, klein 4B 트레이너의 fal 현재 지원 여부 미확인.
