# AI 아이돌 생성 조건과 스펙

2026-11-12 작성 · 원본: [Claude Doc](https://claude.ai/artifact/TvD9S23VnCA142NyzvGtmT)

혼자서도 월 6만 원(1단계)에서 18만 원(MV 제작 달) 수준의 구독 도구로 "얼굴이 고정된 가상 연습생 1명"을 만들 수 있습니다. 핵심 조건은 세 가지입니다. 캐릭터 바이블을 먼저 고정하고, 얼굴은 기준 이미지 세트(또는 LoRA)로 묶고, 실존 인물 유사도 검사를 통과한 얼굴만 씁니다. 1단계(SNS 한 달 일기)에 필요한 최소 세트는 기준 얼굴 1개, 사진 100장, 카툰 기본형 1개, 짧은 영상 5~10개입니다. 음원과 30초 티저 MV는 2단계에 붙입니다.

가격과 기능은 2026년 11월 기준으로 확인한 값이며, 출처는 문서 끝에 있습니다.

## 1. 캐릭터 설계 조건

얼굴과 설정을 글로 먼저 고정해야 이미지 수백 장이 같은 사람으로 보입니다. 생성 전에 아래 항목을 캐릭터 바이블(6장)에 적어 둡니다.

| 항목 | 정해야 할 내용 | 예시 |
| --- | --- | --- |
| 나이 | 성인임이 분명한 설정 나이와 외형 | 27세, 데뷔 늦은 연습생. 교복·학생 설정 금지 |
| 얼굴 | 얼굴형, 눈매, 코, 입, 눈썹, 피부톤, 고유 표식 1~2개 | 갸름한 얼굴, 쌍꺼풀 없는 긴 눈, 왼쪽 눈 밑 점 |
| 헤어 | 기본 헤어 1개 + 컴백용 변주 2~3개 | 흑갈색 가르마펌. 변주: 애쉬 블론드, 짧은 투블럭 |
| 체형 | 키, 체격, 어깨·팔 비율 | 181cm, 마른 근육형, 넓은 어깨 |
| 포지션·성격 | 그룹 내 역할, 말투, 습관 | 메인 댄서, 말수 적고 장난기 있음 |
| 금지 요소 | 절대 바꾸지 않을 것 | 점 위치, 눈 모양, 키 차이 |

**고유 표식이 중요합니다.** 점, 귀걸이 위치, 특정 앞머리처럼 작은 표식이 있으면 사람이 "같은 인물"로 인식하기 쉽고, 검수할 때도 빠르게 걸러낼 수 있습니다.

### 실존 인물 유사도 검사

- 프롬프트에 실존 연예인 이름, "○○ 닮은" 같은 표현을 쓰지 않습니다.
- 기준 얼굴이 정해지면 역이미지 검색(Google 렌즈, Yandex, PimEyes 무료 검색)으로 닮은 실존 인물이 상위에 뜨는지 확인합니다.
- 확인된 K팝 아이돌 사진 몇 장과 얼굴 임베딩 유사도를 비교합니다. 오픈소스 InsightFace(ArcFace) 기준 코사인 유사도 0.4 이상이면 닮았다고 보고 얼굴을 수정하는 것을 권합니다. 이 기준값은 일반적인 경험치라 정확한 법적 기준은 아닙니다.
- 지인 3~5명에게 "누구 닮았냐"고 물어 같은 이름이 2번 이상 나오면 다시 만듭니다.

### 법적 선

- **AI 표시:** 프로필과 게시물에 "가상 인물(AI 생성)"을 표시합니다. 인스타그램·틱톡은 AI 생성 콘텐츠 라벨 기능을 두고 있고, 한국 AI기본법(2026년 1월 시행)도 생성형 결과물 표시 의무를 둡니다.
- **퍼블리시티권:** 실존 인물의 얼굴, 목소리, 이름을 연상시키면 퍼블리시티권·부정경쟁 문제가 생깁니다. 목소리도 실존 가수와 비슷하게 만들지 않습니다.
- **저작권:** 미국 저작권청은 AI가 만든 결과물 자체에는 저작권을 인정하지 않습니다. 이름·로고는 상표로 등록하고, 사람이 손댄 편집본·캐릭터 시트를 기록으로 남겨 둡니다.
- **도구 약관:** 상업적 이용이 허용된 유료 플랜으로만 만듭니다. 무료 플랜은 상업 이용을 막는 곳이 많습니다.

## 2. 이미지 생성 스펙

얼굴 고정은 "참조 이미지로 시작하고, 300장 이상 만들 때 LoRA로 옮기는" 순서를 추천합니다. 참조 방식은 바로 쓸 수 있고, LoRA는 학습 데이터(기준 사진 20~40장)가 있어야 하기 때문입니다.

### 얼굴 고정 방식

| 방식 | 도구 예 | 장점 | 약점 |
| --- | --- | --- | --- |
| 참조 이미지 | Midjourney V7 Omni Reference·편집 모델(참조 최대 4장), Google Nano Banana(Gemini 이미지), Flux Kontext | 학습 없이 바로 사용 | 장수가 많아지면 얼굴이 조금씩 흘러감 |
| 서비스형 얼굴 학습 | Higgsfield Soul ID(사진 20~80장), Leonardo Elements, Scenario 커스텀 모델 | 일관성 높음, 설치 불필요 | 학습한 모델을 밖으로 내보낼 수 없음 |
| 직접 LoRA | Flux 계열 LoRA를 fal.ai·Replicate에서 학습, 또는 ComfyUI | 모델 파일을 내가 소유, 어떤 도구로도 옮김 | 설정이 까다로움 |

1인 개발자에게는 **Midjourney 또는 Nano Banana로 기준 얼굴과 첫 40장을 만들고, 그 중 잘 나온 20~30장으로 Flux LoRA를 학습**하는 조합이 가장 안전합니다. LoRA 파일을 소유하면 나중에 서비스를 바꿔도 얼굴이 남습니다.

### 해상도와 비율

- 생성: 긴 변 최소 1536px. 필요하면 2배 업스케일(Topaz, Magnific 등).
- SNS 피드: 4:5 (1080×1350). 스토리·릴스: 9:16 (1080×1920). 프로필: 1:1.
- 영상 첫 프레임용 이미지는 영상과 같은 비율(9:16 또는 16:9)로 따로 만듭니다.

### 필요한 장수와 카테고리 (총 100~300장)

| 카테고리 | 1단계 최소 | 전체 목표 | 내용 |
| --- | --- | --- | --- |
| 기준 시트 | 10 | 10 | 정면, 좌우 45°, 옆모습, 전신, 무표정. 흰 배경 |
| 표정 | 15 | 30 | 웃음, 집중, 지침, 장난, 울음 직전 등 |
| 연습실 | 25 | 70 | 거울 앞, 땀 흘린 모습, 동작 중간 컷 |
| 일상 | 25 | 80 | 숙소, 편의점, 산책, 이동 중 |
| 무대·화보 | 10 | 50 | 무대 의상, 조명, 콘셉트 화보 |
| 의상 변주 | 15 | 60 | 연습복, 사복, 무대복을 각각 여러 장소에서 |

한 달 일기(하루 1~3개 게시)는 사진 약 60~90장이면 충분합니다. 보통 쓸 만한 컷 1장을 고르려면 4~8장을 뽑기 때문에, 생성량은 최종 장수의 5배 정도로 잡습니다.

### 일관성 검증

1. **자동 검사:** InsightFace로 기준 정면 사진과 각 이미지의 얼굴 유사도를 계산합니다. 경험상 0.6 미만이면 다른 사람으로 보고 버립니다. 에이전트에게 짧은 파이썬 스크립트로 만들어 달라고 하면 됩니다.
2. **체크리스트 검수:** 고유 표식(점 위치), 눈 모양, 손가락 수, 텍스트 깨짐을 눈으로 확인합니다.
3. **나란히 비교:** 한 주 분량을 격자로 펼쳐 보고, 한 장만 다른 사람처럼 보이면 빼냅니다.

## 3. 영상·립싱크·음성 스펙

영상은 "검수한 사진을 첫 프레임으로 넣는 이미지→영상(image-to-video)"만 씁니다. 텍스트만으로 영상을 만들면 얼굴이 매번 달라집니다.

### 영상

| 항목 | 스펙 |
| --- | --- |
| 도구 | Kling(캐릭터 참조·가성비), Google Veo 3.1(소리까지 생성, 초당 약 $0.35), Runway 중 1개를 주력으로 |
| 컷 길이 | 5~10초. 길면 얼굴과 동작이 무너짐 |
| 해상도 | 1080p, 9:16(릴스·쇼츠) 기본. MV는 16:9도 함께 |
| 촬영 장면 | 돌아보기, 걸어오기, 거울 앞 동작 등 단순한 움직임 위주 |
| 춤 | 전체 안무는 아직 깨지기 쉽습니다. 2~3초 포인트 동작만 만들고, 나머지는 실루엣·클로즈업·빠른 편집으로 채웁니다. Kling·Runway의 모션 참조 기능에 내가 추는 영상을 넣는 방법도 있습니다 |
| 생성량 | 쓸 만한 컷 1개당 3~5회 생성을 예상 |

최신 가격 기준 Kling 유료 플랜은 월 $8.80(Standard)·$32.56(Pro)이지만, 상업 이용 라이선스가 명시된 건 상위 플랜뿐이라는 정리도 있습니다. 구독 전에 공식 약관에서 상업 이용 범위를 확인하세요.

### 립싱크

- **말하는 영상(브이로그, 인사):** 사진 1장 + 음성 파일로 만드는 Hedra Character-3, HeyGen 사진 아바타, VEED Fabric 중 하나를 씁니다. 정면에 가까운 얼굴, 입이 가려지지 않은 사진이 잘 됩니다.
- **노래 립싱크(MV):** 노래는 말보다 입 모양이 크고 빠르기 때문에 어색해지기 쉽습니다. 티저에서는 후렴 1~2구절에만 3~5초 넣고, 보컬만 분리해(아래 음악 참고) 넣으면 정확도가 올라갑니다.
- 한 번에 길게 만들지 말고 10초 안쪽으로 나눠 이어 붙입니다.

### 목소리(TTS) 고정

- **도구:** ElevenLabs Voice Design. 실존 인물을 복제하지 않고 문장으로 새 목소리를 만듭니다(예: "20대 후반 한국 남성, 낮고 부드러운 톤, 약간 숨소리").
- **고정 방법:** 마음에 드는 목소리가 나오면 보이스 라이브러리에 저장하고 보이스 ID를 바이블에 적습니다. 안정성·유사도 같은 설정값도 함께 적어 두면 매번 같은 목소리가 나옵니다.
- **기준 샘플:** 한국어·영어 각 30초 샘플을 만들어 "정답 목소리"로 보관하고, 새 녹음을 이것과 비교합니다.
- **플랜:** 무료는 상업 이용 불가. Starter($6/월)부터 상업 이용 가능, Creator($22/월)부터 고품질 보이스 슬롯 1개.

## 4. 음악 스펙

티저용 곡은 Suno Pro($10/월)로 충분합니다. Pro부터 상업 이용이 허용되고, 무료 플랜에서 만든 곡은 나중에 업그레이드해도 상업 이용이 안 됩니다. 그래서 처음부터 유료로 만드세요.

| 항목 | 스펙 |
| --- | --- |
| 도구 | Suno v6 (Pro: 월 크레딧 2,500, 다운로드 20곡 / Premier $30: 다운로드 60곡, Suno Studio) |
| 장르 프롬프트 | "K-pop boy group, dance pop, 120~128 BPM, 강한 훅, 한영 혼합 가사" 처럼 장르·템포로만 적고, 실존 가수·곡 이름은 넣지 않음 |
| 가사 | 직접 쓰거나 Claude와 쓴 뒤 입력. 사람이 쓴 가사는 저작권 주장에도 유리 |
| 출력 | WAV 다운로드 + 스템(보컬/반주) 분리. 보컬 스템은 립싱크에, 반주는 편집에 사용 |
| 목소리 일치 | Suno 보컬은 매번 목소리가 달라집니다. "이 캐릭터의 노래 목소리"로 쓸 크리에이티브 한 곡을 정해 그 목소리를 기준(페르소나) 삼아 이어 만듭니다. 말하는 목소리(TTS)와 완전히 같을 수는 없으니 톤만 비슷하게 맞춥니다 |
| 티저 편집 | 30초 = 인트로 4초 + 빌드업 10초 + 훅 12초 + 엔딩 4초 정도. 120 BPM이면 한 박자가 0.5초라 2박(1초)·4박(2초) 단위로 컷을 자릅니다 |
| 편집 도구 | CapCut(비트 자동 표시) 또는 DaVinci Resolve(무료) |

AI 음원을 음원 유통사(스포티파이 등)에 올릴 때는 유통사별 AI 음원 정책을 따로 확인해야 합니다. 1단계 SNS 티저에는 해당하지 않습니다.

## 5. 카툰 버전 스펙

카툰 버전은 실사 얼굴에서 "알아볼 수 있는 표식 3가지"만 가져오면 됩니다. 예를 들면 헤어스타일, 눈 밑 점, 대표 의상 색입니다.

| 항목 | 스펙 |
| --- | --- |
| 비율 | 2~3등신, 큰 머리, 단순한 눈·입 |
| 기본 시트 | 정면·측면·뒷모습 3면도 + 색상표(헥스 코드 5개 이내) |
| 제작 | Midjourney·Nano Banana에 실사 기준 사진을 참조로 넣고 "chibi, 2-head-tall, flat color" 스타일로 변환. 마음에 드는 시트가 나오면 일러스트레이터가 벡터로 다시 그리게 하는 것을 권합니다(외주 10~30만 원 수준으로 추정). 사람 손을 거친 캐릭터는 저작권 보호가 더 확실합니다 |
| 이모티콘 | 24개 1세트. 카카오 이모티콘은 360×360px PNG, LINE 스티커는 최대 370×320px PNG가 일반적입니다. 제출 전 각 플랫폼의 최신 규격을 확인하세요 |
| 춤 애니메이션 | 카툰은 단순해서 AI 영상으로도 잘 움직입니다. 3면도를 첫 프레임으로 Kling에 넣어 2~5초 루프를 만들고, 반복용은 GIF·WebM으로 내보냅니다. 더 정교한 반복 동작은 벡터 시트를 Rive나 Spine으로 엮는 방법도 있습니다 |
| 배경 | 투명 PNG 기본. 배경이 있는 버전은 따로 저장 |

## 6. 저장·관리 구조

모든 자산은 캐릭터 바이블 하나를 기준으로 만들고, 쓸 만한 결과물은 만든 방법(프롬프트·시드·도구)과 함께 저장합니다. 그래야 나중에 같은 컷을 다시 만들 수 있고, 저작권·출처 증빙도 됩니다.

### 캐릭터 바이블 (bible.md 한 파일)

1. 기본 정보: 이름(한/영), 설정 나이, 생일, 키, 포지션
2. 얼굴 명세: 1장의 표 내용 + 기준 정면 사진 파일명
3. 고정 프롬프트: 모든 생성에 그대로 붙이는 얼굴 문장과 금지 표현
4. 도구 설정: LoRA 파일명·트리거 단어·권장 강도, 보이스 ID·설정값, Suno 기준 페르소나
5. 성격·말투: 말버릇 5개, 쓰지 않는 말, 일기 문체 예시 2개
6. 세계관: 소속사(가상), 연습생 연차, 동료 실루엣 설정
7. 타임라인: 날짜별로 올린 일기와 사건. 설정이 서로 어긋나지 않게 하는 기록
8. 변경 이력: 바꾼 날짜와 이유
