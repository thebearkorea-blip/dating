# 조코딩 가상 인플루언서 레퍼런스 조사 (2026-11-14)

상태: **핵심 대상(조코딩의 AI 가상 인플루언서 프로젝트)은 웹 검색·페치로 확인하지 못했다.** 아래 ①~⑤는 대부분 "미확인"이고, 지어내지 않았다. ⑥ 유사 사례와 일반 도구 정보만 출처가 있다.

## 0. 조사 방법과 한계 (2026-11-14 수행)

- 검색어 7종(한/영: "조코딩 AI 가상 인플루언서 인스타그램", "Jocoding virtual influencer ...", "조코딩 AI 인플루언서 github 블로그" 등)을 WebSearch로 돌렸으나 조코딩 채널·블로그·깃허브에서 해당 프로젝트가 나오지 않았다.
- 조코딩 공식 깃허브(github.com/youtube-jocoding)의 저장소는 animalface, kogpt-interview, chatgpt-api-chatdoge-book 등이고 가상 인플루언서 저장소는 검색에 안 잡혔다. https://github.com/youtube-jocoding/animalface (확인일 2026-11-14)
- 조코딩 인스타(@youtubejocoding)는 개인 계정(약 3.5만 팔로워, 게시물 1,366)이며 실험 계정이 아님. https://www.instagram.com/youtubejocoding/ (검색 스니펫, 날짜 미확인)
- YouTube 페이지는 WebFetch로 본문·설명란이 읽히지 않았다(제목만). oEmbed로 확인한 결과 "AI 인플루언서 직접 만들어봤습니다"(https://www.youtube.com/watch?v=xU_vCE4r-2w)는 채널 **이해든**, "조회수 폭발하는 AI 인플루언서, 무료로 5분 만에 만들어봅니다"(https://www.youtube.com/watch?v=yxwm5whAg5o)는 채널 **AI 머니**이며 **조코딩이 아니다**.
- 가능성: (a) 영상이 있으나 검색 색인에 없음 (b) 요청 전제(조코딩의 인스타 팔로워 증가 프로젝트)가 다른 유튜버와 혼동됨. 둘 다 미확인. **사용자가 영상 URL을 주면 재조사 가능.**

## 7. 우리에게 적용

비교 대상 결정: `docs/decisions.md` "캐릭터·콘텐츠" 절(얼굴 고정 LoRA, SNS 플랫폼, 일상 사진 = 실사진·스톡, 단체 사진 안 함), `docs/ops/sns-rules.md` §8.

근거 수준이 낮으므로 아래는 "조코딩에서 배운 것"이 아니라 "수집된 일반 사례에서 얻은 시사점"이다.

### (a) 그대로 가져올 것
- 캐릭터 LoRA로 얼굴 고정 + 생성물 사람 검수 후 게시: 일반 관행과 일치(§1). 우리 결정 유지.
- AI 라벨 처음부터 ON: 이미 결정됨.
- 일상 컷에 실사진·스톡 혼용: 조코딩 근거는 없으나 사례 조사에서 반례도 없음, 유지.

### (b) 다르게 할 것
- **인스타 단일 채널 의존 금지**: Aitana는 인스타 37만 대비 틱톡 4.8천. 팔로워가 곧 다른 채널로 이어지지 않는다. 우리는 틱톡 1순위·앱 유입이 목적이므로 팔로워 수보다 앱 유입(프로필 링크 클릭) 지표를 본다.
- **외부 수치 벤치마크로 쓰지 않음**: "10일 527K" 류는 홍보성이라 목표치 근거에서 제외. 1단계 판정(가입자 100명)은 기존 기준 유지.
- **소유자 리스크**: 로지는 제작사 폐업(2025-03)으로 활동 중단. 우리는 캐릭터·LoRA·콘텐츠 원본을 저장소 밖 백업으로 우리가 직접 보유(이미 `.data/` 구조, 백업 위치만 확인 필요).

### (c) 즉시 실행 가능한 액션 (5개 이내)
1. 사용자에게 조코딩 영상 URL(또는 정확한 제목) 요청 → 받으면 자막·설명란 기반으로 §1~§5 재조사.
2. 영상 확인 전까지 이 프로젝트 근거로 SNS 계획을 바꾸지 않는다(결정 번복 금지).
3. 위키 외 1차 자료로 Lil Miquela 확인(브랜드 협업·AI 표시 방식) — 필요할 때만.
4. 인스타·틱톡 프로필 링크 클릭 → 앱 가입 전환 지표를 `docs/ops/sns-rules.md` 운영 지표에 한 줄 추가할지 사용자 결정.
5. LoRA·기준 얼굴 원본의 이중 백업 위치 확인(`.data/photos/candidates/` 저장소 밖 보관분).
