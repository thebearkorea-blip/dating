## §1 확인한 사실
- 전체구조 §2.3 스키마 정의, §2.5 격리 장치 1~5.
- UI 조사: 대화 중 구독·광고 끼어들기가 낮은 평점의 주원인(Replika 1점 리뷰 24%). 한도 도달 시 캐릭터 사정으로 마무리하는 우리 설계와 맞음.
- 아직 Neon·Clerk·Vercel 프로젝트 없음 → 사용자 계정 생성 필요(돈·계정 확인 대상).

## §3 작업 단위

### ①a Next.js + PWA + 디자인 토큰 + 앱 목소리 흰 목록
- `src/app/{layout,page}.tsx`, `manifest`, 서비스워커, `src/engine/app-voice.ts`(허용 화면 id: `signup`, `age`, `ai_notice`, `settings`, `safety`, `paywall_morning`, `geo_block`)
- 완료: `next build` 통과, Lighthouse PWA 설치 가능

### ①b Drizzle 4스키마 + 마이그레이션 + 역할
- `src/db/schema/{world,collective,personal,billing}.ts`, `drizzle.config.ts`, 마이그레이션 SQL에 `CREATE SCHEMA`·`CREATE ROLE`·GRANT
- 완료: 빈 Neon에 마이그레이션 적용, `role_billing`으로 `world` INSERT 시 권한 오류(테스트)

### ①c content 적재 스크립트
- `src/db/load-content.ts`: `content/`(bible·group·canon·photos manifest) → `world.*`. 멱등(upsert)
- 완료: 적재 후 `world.characters` 1행, `canon_facts` = canon.jsonl 행 수

### ①d Clerk + 온보딩 + 지역 차단 + 토큰 링크
- `src/app/(auth)/…`, `src/app/onboarding`, `src/app/i/[token]`, `src/policy/age-gate.ts`(생년 → 18+ 판정, 14~17은 "준비 중" 안내 — 팬 모드는 3단계), `proxy.ts`(지오 차단)
- 완료: 실화면 1회 — 가입 → 온보딩 → `/chat` 빈 화면 도달, 토큰 링크로 들어온 경우 `platform_identities` 연결 확인
