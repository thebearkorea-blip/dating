## §1 확인한 사실
- `schedule.activityAt`에 `canInitiate`·`busy`·`mood` 있음(W3). `relationships`에 `push_window`·`push_max`·`last_contact_at`(①). `messages.origin`에 `proactive` 값 정의됨.
- `web-push` 패키지가 없음 → VAPID 서명은 Node `crypto`로 직접 구현하거나 패키지 1개(`web-push`) 설치 필요 — **설치 확인 대상**(기본값: 설치).

## §3 작업 단위

### ④a 선톡 판정·생성 함수 + 로컬 틱
- `src/jobs/proactive.ts`(`decideProactive(rel, now) → candidate|null`, `generateProactive`), `src/tools/proactive-tick.ts`, 감쇠 규칙 `src/engine/catch-up.ts`
- 테스트: 창 밖 → null / `push_max` 도달 → null / 4일 공백 → 하루 1회 / busy=3 → null / 같은 입력 결정적

### ④b 사진 선택 + 미디어 서빙
- `src/engine/photo-pick.ts`, `src/app/api/media/[id]/route.ts`, 채팅 말풍선 이미지 렌더(플레이스홀더 포함)
- 테스트: 재사용 금지 / `private` 우선 / 매니페스트 없으면 null

### ④c Web Push + 설정 화면
- `src/tools/vapid.ts`, `src/db/schema/personal.ts`에 `push_subscriptions`, `public/sw.js`, `src/app/settings/page.tsx`(구독 토글·시간대·`push_max`·AI 고지 재표시·"결제는 그의 성장에 영향 주지 않습니다" 한 줄), `src/jobs/proactive.ts`에서 저장 후 푸시 발송
- 실화면: 로컬 HTTPS 없이도 `localhost`는 Push 허용 — 구독 → 틱 실행 → 알림 수신 1회
