## §1 확인한 사실
- `schedule.activityAt`에 `canInitiate`·`busy`·`mood` 있음(W3). `relationships`에 `push_window`·`push_max`·`last_contact_at`(①). `messages.origin`에 `proactive` 값 정의됨.
- `web-push` 패키지가 없음 → VAPID 서명은 Node `crypto`로 직접 구현하거나 패키지 1개(`web-push`) 설치 필요 — **설치 확인 대상**(기본값: 설치).

### 설계와 다르게 한 것
- 후보 판정 입력은 DB 행이 아니라 스냅샷(`ProactiveInput`)을 받는 순수 함수(테스트 용이).
- 최소 간격 = 푸시 창 길이 ÷ (상한+1), 기준은 마지막 사용자 메시지·선톡 중 늦은 것. 하루 상한 = min(push_max, bible `initiative_per_day`)에 공백 감쇠 적용.
- 선톡 `deliver_at` = 틱 시각, 푸시도 저장 직후 즉시 발송.
- 선톡 생성은 1회 호출, 가드(`guardOutput`)에 걸리거나 예외면 그 틱 건너뜀(재생성·폴백 없음).
- 사진 첨부는 `PROACTIVE_PHOTO_RATE`(기본 0.3) 해시 확률. 파일이 없으면 `/api/media`가 회색 SVG 플레이스홀더를 돌려준다.
- `next.config.ts`에 `web-push`를 serverExternalPackages로 추가. 챗 헤더에 Settings 링크 추가.
