## §2 정의

- 동기화 함수 `syncSubscription(db, userId, sub, now)` 하나가 Stripe 구독 객체 → entitlements를 쓴다(웹훅·복귀 페이지·해지 공통, 멱등).
  - status ∈ {active, trialing, past_due} → plan=paid, dailyQuota=100, currentPeriodEnd=구독 기간 끝, cancelAtPeriodEnd=sub 값
  - 그 밖(canceled, unpaid, incomplete_expired, incomplete) → plan=free, dailyQuota=5(`FREE_DAILY_QUOTA`), cancelAtPeriodEnd=false
  - 항상 stripeCustomerId·stripeSubscriptionId·stripeStatus 기록
- userId 찾기: Checkout `client_reference_id` + `subscription_data.metadata.userId`. 구독 이벤트는 metadata.userId, 없으면 stripeSubscriptionId로 조회.
- 웹훅: `POST /api/stripe/webhook`, `req.text()` 원문 + `stripe-signature` → `constructEvent`(`STRIPE_WEBHOOK_SECRET`). 실패 400, 처리한 이벤트 200, 모르는 이벤트 200(handled:false).
