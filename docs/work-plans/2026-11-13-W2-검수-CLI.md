| 결정 | 내용 | 이유 |
|---|---|---|

## §1 확인한 사실
- 전체구조 §2.2: `guards.yaml` = `{id, scope: input|output|content, kind: regex|classifier, severity: block|flag, text}`.
- 검수 대상 1단계: 일기·캡션·댓글 답글 초안·사진 태그(텍스트). 2단계: 답장(동기 안전 규칙만)·샘플.

## §2 정의
- **block**: 게시·전송 불가. **flag**: 사람 확인 후 결정.
- **정확도**: 골든 20건 중 19건 이상 일치, **위반을 통과로 놓친 것 0건**.

## §3 작업 단위

### W2a guards.yaml + 1단 규칙 엔진

- 완료 기준: 골든 위반 중 regex 대상이 1단에서 잡힘

- 완료 기준: 골든 20건 판정 19/20, 놓친 위반 0
