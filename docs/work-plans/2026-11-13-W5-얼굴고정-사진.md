## §1 확인한 사실
- fal.ai 공식: LoRA 학습 1회 $2(1,000 step), 생성 $0.035/MP, "commercial rights included" 안내. BFL 라이선스 §2(d)·§4(a) 문구 상충(조사 §3) → 별도 조사 진행 중.
- 검수자: 40대 여성 1명. 기준 얼굴 선택과 전수 검수를 맡는다(decisions "검수자").
- A안 서이한: 부산, 21, 메인댄서, 편의점 알바 출신, 동생 둘 — 외형 방향: 건강한 체격, 햇볕에 탄 피부, 웃을 때 눈이 접힘, 짧은 머리(가정 — 검수자 선택으로 확정).

## §2 정의
- **기준 얼굴 세트**: 같은 인물로 보이는 정면·좌우 45°·측면·웃음·무표정 20~40장(LoRA 학습 입력).
- **매니페스트 행**: `{id, blob_url(로컬 경로), situation, time_of_day, place, face, audience, used:[]}` (전체구조 §2.2).

## §3 작업 단위

### W5a 기준 얼굴 후보
- 할 일: 텍스트→이미지로 후보 얼굴 6종 × 각 4컷(정면·45°·웃음·무표정) 생성. 프롬프트에 "성인 남성, 20대 초반, 한국인, 건강한 체격"을 고정하고 **나이 어려 보이는 단서(교복·앳된 얼굴선) 금지**.
- 모델: 메인(프롬프트) + fal.ai
- 완료 기준: 검수자가 6종 중 1종 선택(또는 2종 혼합 지시). `docs/ops/face-selection.md`에 선택 근거 한 줄

### W5b LoRA 학습
- 할 일: 선택 얼굴로 일관 세트 20~40장 생성(같은 시드·참조) → fal.ai 학습 → 테스트 10장으로 일관성 확인(검수자 "같은 사람" 판정 8/10 이상)
- 모델: 메인 + fal.ai
- 완료 기준: LoRA 파일 보관(저장소 밖, 경로를 `docs/ops/face-selection.md`에), 테스트 판정 기록

### W5c 사진 100장 + 매니페스트
- 할 일: `docs/ops/diary-topics.md`의 사진 상황 태그에서 100개 상황을 뽑아 생성. `src/tools/photo-tag.ts`(implementer)로 매니페스트 작성. 이미지 파일은 저장소 밖 로컬 폴더.
- 모델: 메인(생성) + implementer(도구)
- 완료 기준: 매니페스트 100행 전부 태그 완비, `face=false` 50장 이상, `private` 20장 이상, 교복·학교 0장

### W5d 검수
- 할 일: 검수자 전수 검수("미성년으로 보임" / "다른 사람으로 보임" / "통과"), 미성년 판정은 폐기·재생성. 유사도 검사(조사 결과 조합) 결과를 `docs/ops/likeness-check.md`에.
- 완료 기준: 통과 100장, 폐기 사유 기록, 유사도 검사 통과
